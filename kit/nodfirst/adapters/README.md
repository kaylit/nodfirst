# Command files for coding tools

Each playbook can be started with a short command (for example `/nodfirst-specify`). The files here make those commands appear in your coding tool. They only point to the playbooks: the rules live in `nodfirst/playbooks/`.

`init` and `adopt` install them for you (step "Commands for the human's tool"). To install by hand, copy the folder for your tool:

| Tool | Copy from | To (in the project root) | How you call a command |
|---|---|---|---|
| Claude Code | `nodfirst/adapters/claude/` (each `nodfirst-*` folder) | `.claude/skills/` | `/nodfirst-specify …` |
| OpenAI Codex | `nodfirst/adapters/codex/` (each `nodfirst-*` folder) | `.agents/skills/` | `$nodfirst-specify …` (or `/skills`) |
| Cursor | `nodfirst/adapters/cursor/*.md` | `.cursor/commands/` | `/nodfirst-specify …` |
| GitHub Copilot (VS Code, Visual Studio) | `nodfirst/adapters/copilot/*.prompt.md` | `.github/prompts/` | `/nodfirst-specify …` |
| Any other tool | — | — | mention the playbook file: "follow `nodfirst/playbooks/specify.md`" |

**Instructions for the agent installing them:** create the destination folder if missing; copy only files and folders whose name starts with `nodfirst-`; never overwrite or delete other files in those folders; list what you copied. Folders whose name starts with a dot are hidden in Finder and Explorer: tell a Guided user that this is normal.

`CLAUDE.md` at the project root only imports `AGENTS.md`, for tools that read `CLAUDE.md` instead of `AGENTS.md`.

These files are generated by `maintainers/tools/build_adapters.py` in the NodFirst repository (not in this folder); do not edit them by hand.
