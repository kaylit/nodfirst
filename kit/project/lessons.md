# Lessons log

Defects found in review, and the rule each one produced. Optional: no playbook needs this file to run.
Add an entry whenever you correct an agent or a document for a reason that could happen again. If the lesson is general, it can also improve the kit: see the manual, "Keeping the kit healthy".

## Entry format
- **Date / phase:** …
- **What happened:** …
- **Cause:** …
- **Rule added or changed:** … (playbook, template, module or constitution; or "none")
