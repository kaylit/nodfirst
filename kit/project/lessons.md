# Lessons log

Defects found in review, and the rule each one produced. No playbook needs this file to run.
The agent proposes an entry whenever you correct it or a document for a reason that could happen again, and up to three when a feature is closed; it writes only the entries you accept. If the lesson is general, it can also improve the kit: see the manual, "Keeping the kit healthy".

## Entry format
- **Date / phase:** …
- **What happened:** …
- **Cause:** …
- **Rule added or changed:** … (playbook, template, module or constitution; or "none")
