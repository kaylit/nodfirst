# NodFirst 0.1.0 — first public version (pre-release)

**Nothing gets built until you say yes.** NodFirst is a Spec-Driven Development kit in plain Markdown for any AI coding agent: you decide and approve, the agent writes, checks, reports and stops.

Documentation: **https://kaylit.github.io/nodfirst/**

## In this version
- Full cycle: `init` / `adopt` → `specify` → `clarify` → `design` → `plan` → `tasks` → `analyze` → `implement` → `verify`, plus `next` (where are we?) and `fix` (small changes).
- Three working profiles: **Guided** (for people who do not write code), **Solo**, **Team**.
- Independent verification of the finished code, in a fresh chat.
- Commands for Claude Code, OpenAI Codex, Cursor and GitHub Copilot.
- Modules for web, backend, mobile, desktop and library projects.
- A manual for non-technical readers, with a step-by-step start in Claude and Cursor.

## Maturity (please read)
This is an **early version**. The core phases (`specify`, `plan`, `tasks`, `analyze`, `implement`) were used on two real projects before this release. Working profiles, `adopt`, `next`, `verify`, `fix` and the command files are **new and not yet used on a real project**; so are the `backend`, `mobile` and `desktop` modules. The status of every part is in the README.

## Install
Download the ZIP, copy everything inside `kit/` into your project folder, and tell your agent: `follow nodfirst/playbooks/init.md` with a few lines about your project.
