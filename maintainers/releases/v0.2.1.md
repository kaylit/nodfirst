# NodFirst 0.2.1 — light track, end to end (pre-release)

A small update after the first real use of `fix`, `init update` and closing a feature (Shortz, on 0.2.0).

## In this version
- **`init update` no longer asks for release notes.** The kit now ships `nodfirst/CHANGES.md`: for each version, what to replace, profile changes and what it means for work in progress.
- **A light fix knows how it ends.** When you accept the report, the fix is done. If it touched security, the agent asks you to run `/nodfirst-verify` in a new chat first, and you close it with `/nodfirst-verify close`. Light fixes do not go on the roadmap.
- **`verify` understands light fixes:** no task list; it checks the short spec, what it changes, and the commits of the fix.

## Update from 0.2.0
Replace `nodfirst/`, then type `/nodfirst-init update`. Your profile does not need changes.

Full list of changes: `CHANGELOG.md`.
